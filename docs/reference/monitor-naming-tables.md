# Monitor naming tables

Generated by `scripts/docs/gen_monitor_naming_tables.py`; do not edit.

This page lists every legacy-to-canonical name in the monitor rename map `hpcperfstats/dbload/lib/monitor_naming/monitor_variable_rename_map.yaml`, for developers who read older archives or change the map.
The monitor emits only canonical names.
Ingest and analysis still read legacy names through this map: `load_map.py` loads it, `legacy.py` builds the alias tables, and `resolve.py` probes canonical names first, then legacy ones.
The naming rules are in [Monitor naming scheme](../explanation/monitor-naming-scheme.md).
