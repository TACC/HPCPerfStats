# test_runs/

Local, gitignored output from test workflows and agent verification runs.

- **Run logs:** `test_run_log_YYYY-MM-DD.md`, `test_run_log_colima_compose.md`
- **Stress JSON:** `stress/`
- **Update-metrics diagnosis JSON:** `diagnosis/`
- **Optional pytest/workflow captures:** `pytest/`, `workflows/`

How to run tests (commands, prerequisites) lives in **`docs/TESTING.md`**, not here.
